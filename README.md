# Лабораторна робота №2

**Дисципліна:** Розробка програмного забезпечення на платформі Java

**Тема:** Збірка проєкту за допомогою Gradle та робота з Java Collections Framework.

## Опис проєкту

У цьому проєкті створено програму для аналізу серверних логів у форматі Common Log Format. Вона дозволяє знаходити унікальні IP-адреси та визначати адреси, які зустрічаються найчастіше. Для цього програма підраховує кількість входжень кожної IP-адреси та сортує результати за спаданням частоти. Якщо кількість входжень однакова, адреси сортуються за алфавітом. Також передбачено перевірку вхідних даних, щоб некоректні записи не впливали на результати аналізу.

## Визначення варіанта

Варіант визначено за порядковим номером у списку групи.

**Номер у списку:** 9

**Розрахунок:** V = 9 mod 3 = 0

**Варіант V=0:** Аналізатор логів серверів.

## Тестування

Для перевірки роботи програми створено юніт-тести з використанням JUnit 5. Тести перевіряють правильність пошуку унікальних IP-адрес, сортування за частотою входжень, а також обробку некоректних записів і неправильних вхідних даних.

Усього реалізовано 14 тестів для перевірки роботи класу `LogAnalyzer`.

## Запуск тестів

Для запуску тестів необхідно мати встановлену Java. Проєкт використовує Gradle Wrapper для збірки та запуску тестів.

Після завантаження проєкту потрібно відкрити термінал у кореневій папці проєкту та виконати команду:

`.\gradlew.bat test`

Після виконання команди Gradle запускає тести та виводить результати перевірки.

Для повної збірки проєкту використовується команда:

`.\gradlew.bat build`
