# Лабораторна робота №2

**Дисципліна:** Розробка програмного забезпечення на платформі Java

**Тема:** Збірка проєкту за допомогою Gradle та робота з Java Collections Framework.

## Опис проєкту

У цій лабораторній роботі я створила клас `LogAnalyzer` для аналізу серверних логів. Програма обробляє записи про звернення до сервера та знаходить IP-адреси, з яких надходили запити.

Для цього реалізовано два методи. Метод `getUniqueIps()` знаходить усі унікальні IP-адреси, а `getTopIps()` визначає, які адреси зустрічаються найчастіше. Результати сортуються за кількістю входжень, а якщо вона однакова, то за алфавітом. Також програма перевіряє формат записів і пропускає ті, що містять помилки.


## Визначення варіанта

Варіант визначено за порядковим номером у списку групи.

**Номер у списку:** 9

**Розрахунок:** V = 9 mod 3 = 0

**Варіант V=0:** Аналізатор логів серверів.

## Тестування

Для перевірки програми я написала 14 тестів із використанням JUnit 5. За допомогою них перевірила роботу обох методів, правильність сортування IP-адрес, а також обробку порожніх списків, неправильних записів і некоректних вхідних даних.

## Запуск тестів

Для перевірки роботи програми я запускала тести та виконувала збірку проєкту за допомогою Gradle Wrapper.

Після завантаження проєкту необхідно відкрити термінал у його кореневій папці та виконати команду:

`.\gradlew.bat test`

Для перевірки повної збірки проєкту використовується команда:

`.\gradlew.bat build`
